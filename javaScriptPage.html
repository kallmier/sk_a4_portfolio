Web Skills

HTML

HTML (HyperText Markup Language) is the standard language used to create the structure of a webpage. It is used to organise content such as headings, paragraphs, images, and links so that a web browser can display them correctly.

Through this subject, I have learned how to use HTML to build multi-page websites, create navigation menus, structure content using headings and lists, and include elements such as images, links, and contact details. I have also learned the importance of writing clear and well-commented code.

CSS

CSS (Cascading Style Sheets) is used to control the appearance and layout of a webpage. While HTML provides the structure, CSS is responsible for the visual design, including colours, fonts, spacing, and alignment.

I have learned how to use inline, internal, and external CSS to style webpages. I have also used CSS to apply different text styles, background colours, and layout adjustments, as well as working with selectors such as classes and IDs to control specific elements on a page.

Tools I Use

I am using Visual Studio Code (VS Code) as my primary development environment to write and manage my HTML and CSS files. VS Code allows me to organise my project files, view my code clearly, and make edits efficiently.

I also use a web browser such as Google Chrome to test and preview my webpages, which helps me identify any layout or formatting issues and make improvements as needed.

Reflections

One of the most challenging aspects I have encountered is ensuring that HTML and CSS work correctly together. Small mistakes, such as incorrect file paths or missing links, can prevent styles from being applied properly, which can be frustrating to troubleshoot.

I have also found CSS to be quite detailed and sometimes difficult to work with, as small changes can significantly affect the layout and appearance of a webpage. However, through practice, I am becoming more comfortable with how CSS controls design and presentation.
